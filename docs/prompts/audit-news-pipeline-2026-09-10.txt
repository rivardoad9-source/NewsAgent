CONTEXT — what this system does
- A cron runs `scripts/tick.py` every 5 minutes (was every 15). For each tracked indicator
  (CPI, PPI, NFP/jobs, unemployment, GDP...) it looks for a NEW observation and, when found,
  computes actual vs previous, reads the market reaction, produces a deterministic verdict
  (rule engine — explicitly NO LLM in this path) and SENDS a Telegram alert.
- Two detection paths now: the FRED path (historical-only, lags 1-3h) and, since 10 Sep 2026,
  a FAST path that reads the official BLS API v1 (keyless, fresh at release time) and fires
  within ~5 minutes. The fast path runs FIRST and the FRED path must then dedupe against it.
- Precedent for why this audit exists: on 10 Sep the PPI alert reached the operator ~1 h late
  because FRED had not published, and it had to be sent by hand. The fast path was built to remove
  that dependency. It has since fired once, live, successfully.
